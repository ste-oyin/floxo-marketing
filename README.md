# Floxo Marketing

Marketing website for [Floxo](https://floxo.io) — spatial intelligence for physical spaces.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Branch Strategy

| Branch | Environment |
| --- | --- |
| `main` | Production (floxo.io) |
| `test` | Staging / QA |
| `development` | Active development |
